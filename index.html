🚗 Vehicle Auction Price Prediction Engine

XGBoost residual-delta model · serverless REST API on GCP
+
Problem
At wholesale auctions the base valuation (Manheim Market Report) tracks the final price almost 1:1, so models lazily split on it — target leakage — and never learn how the actual vehicle traits drive the bid.
Approach
Reframed the target as the markup/discount versus market (Selling Price − MMR), forcing 89 engineered features to explain price. Trained an XGBoost regressor on 500k+ records, then containerized it and shipped a serverless REST API on Google Cloud Run.

👁️ Vehicle Damage Classification (CNN)

Transfer learning with EfficientNetB0 · 8 damage classes
+
Problem
Real salvage photos are noisy — unpredictable angles, poor lighting, and heavy class imbalance — so CNNs trained from scratch overfit to the background instead of the damage.
Approach
Used transfer learning on a frozen EfficientNetB0 (ImageNet) with fine-tuned top layers for 8 damage classes, plus dynamic augmentation (rotation, shifting, zoom, flips). Early stopping and checkpointing captured the peak weights.

⚡ Live Ride-Share Surge-Pricing Engine

Streaming pipeline: Redpanda → PySpark → Redis
+
Problem
Surge pricing needs live supply/demand per zone from a messy event firehose — late events, duplicates, and GPS dropouts — without ever crashing the pipeline.
Approach
Built a four-stage streaming system: an async event generator → Redpanda (Kafka) → PySpark Structured Streaming with 30-second tumbling windows, a one-minute watermark and exactly-once dedup → Redis for sub-millisecond lookups. Prometheus + Grafana dashboards and a documented fault-tolerance recovery story round it out.

World Cup 2026 — Prediction Engine

My flagship football project: a standalone web app that predicts the 2026 World Cup. It blends a composite Elo rating with recent form and FIFA rankings, estimates scorelines with a Poisson-style goal model, and runs Monte Carlo simulations of the group stage — all 48 teams and 12 official groups from the December 5, 2025 draw. An optional, bring-your-own-key LLM mode generates written scouting reports.
